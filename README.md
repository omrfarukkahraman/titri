## 🎯 Proje Hakkında (About the Project)

Titri, görsel ve işitsel uyarıcılara boğulmuş olan dijital mesajlaşma dünyasını; görme/işitme engelliler, sevgililer ve uzak mesafe ilişkisi yaşayanlar için ekrana bakma zorunluluğu olmayan **"saf dokunsal (haptik)"** bir sosyal ağa dönüştürür. 

Rakipler "fiziksel iletişim" kurmak için binlerce liralık akıllı bileklikler (donanım) satmaya çalışırken; Titri, herkesin cebindeki akıllı telefonun titreşim motorunu kullanarak sıfır ek maliyetle birbirlerine "dokunmalarını" sağlar.

***TÜBİTAK 2242 ve T3 Girişim Merkezi için geliştirilen MVP versiyonudur.***

## ✨ Özellikler (Features)

- ⚡ **Haptik İkonlar (Tactons):** Mors alfabesinin yüksek öğrenme bariyeri yerine, kalp atışı veya "kahve içelim" gibi kavramsal titreşim kodları.
- 🚀 **Sıfır Donanım Maliyeti:** Harici bir cihaza ihtiyaç duymaz. Tamamen yazılımsal.
- 📡 **Gerçek Zamanlı (Realtime):** Firebase altyapısı sayesinde iki cihaz arasında 200ms altı titreşim aktarımı.
- 🤝 **Ar-Ge Test Modu:** Bilimsel veriler ışığında haptik geri bildirim algısının testi.
- ♿ **Erişilebilirlik:** Görme ve işitme engelli bireylerle tam uyumlu UI (TalkBack/VoiceOver).

## 🛠️ Kullanılan Teknolojiler (Tech Stack)

* **UI: Framework:** Flutter (Dart)
* **Backend:** Firebase (Firestore & Firebase Cloud Messaging)
* **State Management:** Riverpod
* **Routing:** GoRouter
* **Hardware API:** Vibration Package

## 📱 Kurulum (Installation)

1. Projeyi bilgisayarınıza klonlayın:
```bash
git clone https://github.com/omrfarukkahraman/titri.git
```
2. Bağımlılıkları yükleyin:
```bash
flutter pub get
```
3. Uygulamayı başlatın:
```bash
flutter run
```

# Titri 📳

Haptic-first communication MVP built with Flutter and Firebase. The project explores sending simple meaning through custom vibration patterns instead of relying only on visual or audio notifications.

## Project Idea

Titri uses the phone's vibration motor as a communication channel. Users can send predefined haptic patterns such as a heartbeat-style signal or other custom vibration codes.

The MVP was developed around an accessibility and lightweight communication concept, without requiring additional wearable hardware.

## Highlights

## Getting Started

```bash
git clone https://github.com/omrfarukkahraman/titri.git
cd titri
flutter pub get
flutter run
```

Firebase platform configuration is required before running the full messaging flow.
